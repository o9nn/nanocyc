<span class="hljs-comment"># Neural Network Package #</span>

This package provides an easy and modular way to build and train simple or complex neural networks using [Torch](https://github.com/torch/torch7/blob/master/README.md):
 * Modules are the bricks used to build neural networks. Each are themselves neural networks, but can be combined with other networks using containers to create complex neural networks:
   * [Module](doc/module.md#nn.Module): abstract class inherited by all modules;
   * [Containers](doc/containers.md#nn.Containers): composite and decorator classes like [`Sequential`](doc/containers.md#nn.Sequential), [`Parallel`](doc/containers.md#nn.Parallel), [`Concat`](doc/containers.md#nn.Concat) and [`NaN`](doc/containers.md#nn.NaN);
   * [Transfer <span class="hljs-built_in">functions</span>](doc/transfer.md#nn.transfer.dok): non-linear <span class="hljs-built_in">functions</span> like [`Tanh`](doc/transfer.md#nn.Tanh) and [`Sigmoid`](doc/transfer.md#nn.Sigmoid);
   * [Simple layers](doc/simple.md#nn.simplelayers.dok): like [`Linear`](doc/simple.md#nn.Linear), [`Mean`](doc/simple.md#nn.Mean), [`Max`](doc/simple.md#nn.Max) and [`Reshape`](doc/simple.md#nn.Reshape);
   * [Table layers](doc/table.md#nn.TableLayers): layers <span class="hljs-keyword">for</span> manipulating `table`s like [`SplitTable`](doc/table.md#nn.SplitTable), [`ConcatTable`](doc/table.md#nn.ConcatTable) and [`JoinTable`](doc/table.md#nn.JoinTable);
   * [Convolution layers](doc/convolution.md#nn.convlayers.dok): [`Temporal`](doc/convolution.md#nn.TemporalModules),  [`Spatial`](doc/convolution.md#nn.SpatialModules) and [`Volumetric`](doc/convolution.md#nn.VolumetricModules) convolutions;
 * Criterions compute a gradient according to a given loss <span class="hljs-keyword">function</span> given an input and a target:
   * [Criterions](doc/criterion.md#nn.Criterions): a list of all criterions, including [`Criterion`](doc/criterion.md#nn.Criterion), the abstract class;
   * [`MSECriterion`](doc/criterion.md#nn.MSECriterion): the Mean Squared Error criterion used <span class="hljs-keyword">for</span> regression;
   * [`ClassNLLCriterion`](doc/criterion.md#nn.ClassNLLCriterion): the Negative Log Likelihood criterion used <span class="hljs-keyword">for</span> classification;
 * Additional documentation:
   * [Overview](doc/overview.md#nn.overview.dok) of the package essentials including modules, containers and training;
   * [Training](doc/training.md#nn.traningneuralnet.dok): how to train a neural network using [`StochasticGradient`](doc/training.md#nn.StochasticGradient);
   * [Testing](doc/testing.md): how to <span class="hljs-built_in">test</span> your modules.
   * [Experimental Modules](https://github.com/clementfarabet/lua---nnx/blob/master/README.md): a package containing experimental modules and criteria.

<span class="hljs-comment">## What Was Implemented</span>

<span class="hljs-comment">### 1. Container Modules</span>
Containers allow composition of neural network components:

- **Sequential**: Chains modules together <span class="hljs-keyword">in</span> feed-forward fashion
  - Example: `sequential([Linear1, Tanh, Linear2, LogSoftMax])`
  - Forward pass automatically flows through all modules <span class="hljs-keyword">in</span> order

- **Concat**: Applies multiple modules to same input and concatenates outputs
  - Example: `concat(1, [Branch1, Branch2])`
  - Useful <span class="hljs-keyword">for</span> parallel processing paths

<span class="hljs-comment">### 2. Activation/Transfer Modules</span>
Standardized activation <span class="hljs-built_in">functions</span> as modules:

- **Sigmoid**: Logistic sigmoid <span class="hljs-keyword">function</span> (0 to 1 range)
- **Tanh**: Hyperbolic tangent (-1 to 1 range)
- **ReLU**: Rectified Linear Unit (max(0, x))
- **SoftMax**: Converts logits to probabilities (sums to 1)
- **LogSoftMax**: Log of SoftMax (numerically stable <span class="hljs-keyword">for</span> classification)

All can be used via `module_forward/3` <span class="hljs-keyword">for</span> consistent interface.

<span class="hljs-comment">### 3. Criterion/Loss Modules</span>
Multiple loss <span class="hljs-built_in">functions</span> <span class="hljs-keyword">for</span> different tasks:

- **MSECriterion**: Mean Squared Error <span class="hljs-keyword">for</span> regression
- **ClassNLLCriterion**: Negative Log Likelihood <span class="hljs-keyword">for</span> multi-class classification
  - Use with LogSoftMax output
- **BCECriterion**: Binary Cross Entropy <span class="hljs-keyword">for</span> binary classification
- **AbsCriterion**: L1/Absolute Error loss

All support both forward (loss computation) and backward (gradient computation).

<span class="hljs-comment">### 4. Simple Layer Modules</span>
Building blocks <span class="hljs-keyword">for</span> network construction:

- **Linear**: Fully connected linear transformation (y = Wx + b)
- **Identity**: Pass-through layer (useful <span class="hljs-keyword">in</span> containers)
- **Reshape**: Reshape tensor dimensions
- **Mean**: Reduction by mean along dimension
- **Max**: Reduction by max along dimension
