## R-Lingua (Relevance Lingua<span class="hljs-punctuation">,</span> `.rli`)

R-Lingua is the **Relevance Realization DSL** — a language extension focused on Vervaeke's Relevance Realization theory with the **trielectic ennead architecture**.  It sits alongside P-Lingua (`.pli`) and M-Lingua (`.mli`) without changing either existing pipeline.

### Core Concepts

| Concept | Description |
|---------|-------------|
| **Trielectic ennead** | <span class="hljs-number">9</span> dimensions across <span class="hljs-number">3</span> triads (Agent<span class="hljs-punctuation">,</span> Arena<span class="hljs-punctuation">,</span> Relation) |
| **Grip index** | Per-node measure of optimal cognitive grip ∈ <span class="hljs-punctuation">[</span><span class="hljs-number">0</span><span class="hljs-punctuation">,</span><span class="hljs-number">1</span><span class="hljs-punctuation">]</span> |
| **Ennead balance** | How evenly the <span class="hljs-number">9</span> dimensions contribute (high = stable) |
| **Relevance gradient** | ∇ℜ = log(affordance_realization / affordance_potential) |
| **Emergence score** | Fraction of nodes that have achieved emergent relation status |

### Ennead Triads

| Triad | Pole | Dimensions |
|-------|------|------------|
| **A** | Agent | identity_continuity<span class="hljs-punctuation">,</span> skill_readiness<span class="hljs-punctuation">,</span> motivational_valence |
